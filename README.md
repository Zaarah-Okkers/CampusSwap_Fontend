# CampusSwap SA — Student Peer-to-Peer Marketplace & Residence Services

CampusSwap SA is South Africa's secure, student-only platform for peer trading, textbook exchanges, campus service booking, and residence maintenance.

## Recommended Tech Stack & Setup

- Vue 3 + Vue Router + Vite
- SweetAlert2 for notifications
- Flexbox / CSS Grid with glassmorphism design tokens

## Development Setup

```sh
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```
